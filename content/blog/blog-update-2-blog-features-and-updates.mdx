Long time no update.

Until now, the blog was unsorted and blog posts, projects, and client work, once added, could not be edited except through a new commit.

In this update, I added the ability to edit posts, projects, and client work through repurposing the forms used to create them. I also changed the date input from text to a dropdown menu, as is more common. When edited, the corresponding file is edited and is committed to this site's GitHub repo. This is the most efficient solution because it reduces the overhead that would come with using a database or a headless CMS, although if edit frequency increases one of those solutions would be more effective to reduce the number of redeploys.

For functionality on the visitors' end, I added the ability to sort and filter blog posts. While this is not necessary at the moment, as the blog becomes more populated with posts it will increase ease of use.

The added features make the site more usable for both me and visitors. I still have to add the ability to preview blog posts, projects, and client work before publishing them, as well as a way to filter and sort projects and client work (reusing the same logic for blog posts) and a way to edit tags.
